# 018 — Island-group maps (Luzon, Visayas, Mindanao) · plan

> Produced by Claude Code **plan mode**, then saved here once approved.

## Context

Issue #2 asks for Luzon/Visayas/Mindanao boundaries. This change adds a fifth output level,
`islandgroups/`, dissolved from the 2026-3q region layer by a mapping CSV, and ships it now from
the existing 2026-3q build. A scratch trial already showed that simplify-then-dissolve keeps every
vertex inside `country/`'s set at the same resolution, and that Luzon's only hole is Laguna de Bay.

Facts found while planning:
- `scripts/fetch-shapefiles.sh` finds the main checkout through `git rev-parse --git-common-dir`,
  so it resolves `../philippines-psgc-shapefiles/release-staging/2026-3q` from the worktree too.
  No `PSGC_STAGING` is needed.
- The build directory is the gap. `2026-3q/` (436 MB, gitignored) exists only in the main
  checkout, and its medres/lowres still match `latest/` exactly (all 16 level × format × res dirs
  checked with `diff -rq`). `publish-latest.sh` needs a complete build under the *worktree's*
  root, because every script finds `ROOT` from its own path.

### Script design (`scripts/topojson-islandgroups.sh`)

```
ROOT/TAG/QUARTER arg check as topojson-country.sh; fetch-shapefiles.sh "$TAG" "$QUARTER"
MAP=$ROOT/scripts/island-groups.csv; CSV=$SHAPEFILE/PH_Adm1_Regions.csv
# R2, before anything is written or removed:
#  - every island_group ∈ {Luzon,Visayas,Mindanao}
#  - no duplicate codes in MAP
#  - comm -3 of sorted code lists of CSV and MAP is empty (reports missing / extra by code)
#  any failure: echo the codes to stderr, exit 1
unzip PH_Adm1_Regions.shp.zip into $SHAPEFILE/country/ (same place country uses)
rm -rf + mkdir -p $QUARTER/{geojson,topojson}/islandgroups/{hires,medres,lowres}
for (pct suffix res) in (10% 0.1 hires) (1% 0.01 medres) (0.1% 0.001 lowres); for fmt:
  mapshaper $SHP -simplify $pct keep-shapes \
    -join $MAP keys=adm1_psgc,adm1_psgc field-types=adm1_psgc:number \
    -dissolve island_group sum-fields=area_km2 -rename-layers islandgroups \
    -proj wgs84 -o format=$fmt id-field=island_group $OUT/$res/islandgroups[.topo].$suffix.json
```

If the summed `area_km2` carries float noise, round it to match the source's whole-number values.

## Rollback

`git revert` undoes everything committed. Not covered by it:
- Once `master` is pushed, the four `latest/*/islandgroups/` URLs are live and hotlinkable.
  Removing them later breaks those links. That's a decision, not a rollback.
- Once a release with the island groups is published, its assets are permanent (invariant).
- Local, uncommitted: the worktree's cloned `2026-3q/` (`rm -rf` it, or `/sdlc:close` removes the
  worktree), and islandgroups output added to the main checkout's `2026-3q/` for the release
  (`rm -rf 2026-3q/{geojson,topojson}/islandgroups` there).
